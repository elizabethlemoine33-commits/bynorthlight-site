What Makes a Good Rock
  1. Specific — clear enough to have a done state
  2. Completable in 90 days
  3. Binary — done or not done
  4. One owner — not "the team"
  5. Important enough to protect all quarter
Done When

Write the done definition before the quarter begins — not at the end.

At quarter close: Done = completion criteria met. Not Done = they weren't. No debate, no partial credit.

L10 weekly: On Track or Off Track. If off track, it goes on the Issues list.

The 80% Target

≥ 80% completed — healthy. You're setting Rocks well and protecting them.

100% every quarter — Rocks aren't ambitious enough, or the team is underreporting off-track status.

Consistently < 80% — investigate. Too many Rocks, too vague, or business-as-usual is winning.
